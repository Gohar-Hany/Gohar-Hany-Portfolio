## 🎯 About

My personal developer portfolio — a modern, interactive single-page application showcasing my projects, skills, and experience in AI automation and full-stack engineering.

## ✨ Features

- ⚡ **Blazing Fast** — Built with Vite + React for instant loading
- 🎨 **Premium Dark Theme** — Sleek glassmorphism design with smooth animations
- 📱 **Fully Responsive** — Pixel-perfect across all devices
- 🧩 **Interactive Projects** — Filterable project grid with detailed modals
- 🛠️ **Skills Section** — Visual skill showcase with proficiency indicators
- 📬 **Contact Form** — Direct email integration

## 🛠️ Tech Stack

| Technology | Purpose |
|---|---|
| **React** + **TypeScript** | UI framework |
| **Vite** | Build tool |
| **TailwindCSS** | Styling |
| **Shadcn/UI** | Component library |
| **Vercel** | Deployment |

## 🚀 Quick Start

```bash
git clone https://github.com/Gohar-Hany/Gohar-Hany-Portfolio.git
cd Gohar-Hany-Portfolio
npm install
npm run dev
```
